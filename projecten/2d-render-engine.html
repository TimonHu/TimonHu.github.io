2D Render Engine

Een minimalistische WebGL-2D-engine voor het visualiseren van sprites in de browser.

Bekijk de code op GitHub

Over dit project

Dit is een minimalistische WebGL-2D-engine die laat zien hoe je met shaders, textures en een renderloop sprites tekent in de browser, met een duidelijke scheiding tussen engine-code en gebruikerscode.

Doel

Het creëren van een minimalistische sprite-render engine

Technologieën

HTML, CSS, JavaScript en WebGL
