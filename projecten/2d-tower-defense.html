Over dit project

Ik wilde een game maken voor mijn keuzevak game developer en ik koos voor een tower defense. Ik heb een scene systeem gemaakt en een user interface. CMake was moelijk om op te zetten, maar ik heb het laten werken. Hiermee heb C++ en raylib geleerd.

Doel

Het leren van game development met C++ en raylib.

Technologieën

C++, raylib, cmake
