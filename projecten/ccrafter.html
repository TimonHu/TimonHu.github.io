Over dit project

Een build systeem is een programma dat je code automatisch omzet in een echt programma dat je kan starten. Normaal moet je daarvoor veel losse stappen doen, zoals bestanden compileren en samenvoegen. Een build systeem doet al dat werk voor je met één commando. Veel bestaande build systemen zijn best moeilijk om te leren. Daarom heb ik CCrafter gemaakt: een simpele tool die makkelijk te gebruiken is, maar je toch veel controle geeft.

Doel

CCrafter is ontworpen om een eenvoudig en krachtig build systeem voor C/C++ projecten te bieden.
