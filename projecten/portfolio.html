Portfolio website

Een modern portfolio voor zelfstandige creatievelingen.

Bekijk de code op GitHub

Over dit project

Deze projectpagina toont een strak ontwerp met overzichtelijke projectkaarten, heldere typografie en een responsieve layout.

Doel

Het creëren van een professioneel webprofiel waarmee bezoekers eenvoudig werk en contactinformatie kunnen vinden.

Technologieën

HTML, CSS, Bootstrap, JavaScript.

Belangrijkste onderdelen

  • Responsief grid met projectcards
  • Duidelijke navigatie via een gedeelde `nav.html`
  • Toegankelijke opbouw met semantische secties

Kleurenschema

Deze kleuren vertegenwoordigen de visuele stijl van het portfolio.

Kleur Hex Toepassing
Donker achtergrond #0B1220 Achtergrond, hero-secties, footer
Oppervlak #172441 Kaarten, secties, navigatie
Accent #5D9CFF Knoppen, links, highlights
Secundair accent #64D4FF Links, iconen, call-to-actions
Tekst #F4F7FF Primaire tekst, koppen, bodytekst
